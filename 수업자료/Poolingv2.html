PyTorch 실도로 주행 코드 연동 완벽 가이드

aicarA.ipynb 또는 ar.py에서 학습된 가중치를 거쳐 나온 실시간 피처맵 텐서를 추출하여 이 웹 도구에 주입해 보세요.

브라우저 환경의 연산 한계 극복을 위해, 학생들이 학습시킨 실제 신경망의 차원 변화 데이터를 고스란히 저장해 줄 수 있는 초간단 Python 모듈입니다. 아래 스크립트를 복사하여 코랩 또는 로컬 주행 코드의 predict_steering 함수나 추론 로직 맨 끝에 복사해 넣기만 하면 실시간 피처맵이 포함된 파일(pilotnet_features.json)이 내려받아집니다.

ar.py or aicarA.ipynb (Feature Map Exporter) 
import json
import torch
import numpy as np

# PyTorch 모델 피처맵 일괄 추출용 헬퍼 함수
@torch.no_grad()
def export_pilotnet_features(model, input_tensor, save_path="pilotnet_features.json"):
    """
    model: NvidiaModel (NVIDIA PilotNet) 인스턴스
    input_tensor: [1, 3, 66, 200] 크기의 전처리 완료된 PyTorch Tensor
    """
    features = {}
    model.eval()
    
    # 1. 입력 원본 데이터 보관 (H x W x C 형태로 저장)
    inp = input_tensor.squeeze(0).cpu().numpy() # [3, 66, 200]
    # RGB 변환 및 역정규화(0-255)
    inp = (inp * 255.0).astype(np.uint8).transpose(1, 2, 0)
    features["input"] = inp.tolist()
    
    # 2. 레이어 바이 레이어 전달하며 각 단계별 텐서 특징맵 수집
    x = input_tensor
    conv_indices = {0: "conv1", 2: "conv2", 4: "conv3", 6: "conv4", 9: "conv5"}
    
    for idx, layer in enumerate(model.layer1):
        x = layer(x)
        if idx in conv_indices:
            name = conv_indices[idx]
            # [1, Channels, Height, Width] -> [Channels, Height, Width]
            tensor_np = x.squeeze(0).cpu().numpy()
            
            # 대표 채널 0번 및 평균 피처맵 2가지를 전송하여 정교성 대폭 강화!
            features[name] = {
                "ch0": tensor_np[0].tolist(),
                "mean": tensor_np.mean(axis=0).tolist(),
                "channels": int(tensor_np.shape[0])
            }
            
    # 3. 브라우저가 다이렉트로 해석할 수 있는 JSON 파일 저장
    with open(save_path, "w") as f:
        json.dump(features, f)
    print(f"🎉 성공: 실제 피처맵 데이터가 '{save_path}' 파일로 저장되었습니다.")
    print("이제 우측 상단의 [PyTorch 피처맵 연동] 버튼을 통해 웹 실습 도구에 드롭하세요!")
💡
연동 성공 시의 변화:
  • 진짜 가중치 활성화: 임의 계산(수식 필터링)이 아닌, 인공지능이 실제 딥러닝 트랙을 가중치 연산하여 강조해낸 특징들이 활성화됩니다.
  • 채널 정보의 실시간 확인: JSON에 포함된 다채널 대표 값을 로딩하여 마지막 레이어들의 차원 축소가 그라데이션이 아닌, 실제 조향 텐서 맵 형태로 선명하게 복원됩니다.
